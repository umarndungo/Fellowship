# Inuka Fellowship Projects

This repository contains the coursework and hands-on exercises completed during the Inuka Fellowship Data Analytics and AI apprenticeship. It brings together notebooks, scripts, analysis artifacts, and short reports created across the program.

## Project context

The work in this repository focuses on practical data analysis, operational diagnostics, and applied AI workflows. The projects move from data cleaning and exploration to anomaly detection, root cause analysis, and structured reporting for business stakeholders.
